# Uruchamianie projektu

Projekt został stworzony w technologii **React** z wykorzystaniem **Vite** jako bundlera.

### Wymagania

- Node.js w wersji 18 lub wyższej
- npm (dołączony do Node.js)

### Instalacja i uruchomienie

1. Sklonuj repozytorium lub pobierz paczkę ZIP:
```bash
git clone https://adres-do-repozytorium.git
cd nazwa-katalogu
```

2. Zainstaluj wszystkie zależności:
```bash
npm install
```

3. Uruchom projekt w trybie deweloperskim:

``` bash
npm run dev
```

4. Otwórz przeglądarkę i przejdź pod adres:

``` bash
http://localhost:5173
```
